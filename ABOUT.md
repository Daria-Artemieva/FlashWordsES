# About

FlashWordsES is a small Flask web app for learning Spanish vocabulary: you can add words, review them, and practice with flashcards and a simple test mode.

## Why I built it

I started this project because I’m learning Spanish and wanted a lightweight tool to practice every day.
This is my first “vibe coding” project, built together with Codex.

## Tech

- Backend: Python + Flask
- Frontend: HTML + CSS + vanilla JavaScript
- Storage: SQLite (separate word lists per user)
